# BlenderLens 下一步计划（2026-10-18，基于 0.7.0）

这份计划来自三路调研：变形镜头专利普查、渲染技术与 Blender 平台现状、真实镜头的公开实测数据。
结论和出处见文末「调研摘要」；候选专利 PDF 在仓库根目录 `research_candidates/patents/`（不进扩展包）。

总目标不变：**用真实处方追迹，画面的每个特征都能指回一个专利数字或一条公开实测。**
新增一条衡量标准：**每个预设至少有一项可以对照外部数据的回归测试**（不只是对照专利自身）。

## 0.8 —— 准确性与采样（2026-10-18 完成，详见 RESEARCH.md §6.9）

| # | 结果 |

| 8.1 | **改做了更便宜的版本**：实测采样浪费几乎全来自盒子余量，加密表 → 带光占比 0.54 → 0.62–0.74（预设表随包分发）。牛顿瞄准光阑的上限只有约 0.72–0.91、每采样要多 3–9 次追迹，不做 |

| 8.3 | ✅ 单层 / 三层宽带膜（特征矩阵法），OSL、GPU、炫光通道同一实现；Neil 与 Panavision 后置默认宽带膜 |
| 8.4 | ✅ 一阶等效补偿板 + 凸轮表；C/E/G 默认完全补偿（外部数据三项旁证：ARRI 近摄压缩比、垂直呼吸、2:1 椭圆焦外）。没有做「任意角度旋转柱面」——补偿不需要它；Caldwell 预设（9.4）需要时再做 |
| 8.5 | ✅ 合成 ISO 9358 测试测出的 VGI = 设定值（< 1%）；不环绕；4K 0.6 s。随视场 / 波长变化没有做：没有任何数据可依 |
| 8.6 | **部分**：发现并补上 Geometry 模式缺失的光圈（之前只靠 1.4 倍出瞳采样盘限光）；修掉两处法线量化（Blender 16 位角度、Cycles 八面体 0 值偏置）。Panavision 长焦端仍有全画面一致的约 (+0.27, −0.40) px（270p）平移：网格密度、薄膜、偏心倾斜、相机坐标系都已排除（RESEARCH §5 第 14 条）——留到 0.9 |
| 8.7 | ✅ `tests/test_reference.py` |

原计划：

| # | 项目 | 做法 | 验收 | 工作量 |
|---|---|---|---|---|
| 8.1 | **光圈瞄准采样**（Hanika & Dachsbacher 2014 思路，用精确追迹代替多项式） | 在光阑上采样一点，从传感器点用 2–4 步牛顿迭代（有限差分雅可比）求出射方向；OSL 与 GPU 内核共用。迭代不收敛时退回现在的 pupil box | 画面边缘 f/2 噪声（原始方差）比 0.7 降 ≥ 2×；散景形状与 Geometry 模式一致；CPU/GPU 差 < 0.1% | 中 |
| 8.2 | **波长分层采样** | 每像素按样本序号分层取 λ（或 Cycles 给的第二维随机数），按 CMF 之和做重要性采样；校验平坦光谱积分恰为白 | 色散边缘与鬼影的色噪比 0.7 降 ≥ 3×（bl_dispersion 加指标）；白场色偏 < 0.1% | 小 |
| 8.3 | **多层镀膜（Abelès 特征矩阵）** | 每面一个膜系 `coating: [{n, d_nm}, …]`，斜入射，s/p 平均；OSL、GPU、flare.py 共用一个生成的表（按角度 × 波长查表，代价可忽略）。预设：C 风格 = 单层 MgF₂（设计波长可调，用来复现 Sasaki 说的蓝紫 → 红蓝）；Neil / PV = 三层 QHQ 宽带膜 | 单测：裸玻璃 4.0%、MgF₂ @550 nm 1.2–1.4%、宽带膜 420–680 nm < 0.5%；同一场景鬼影颜色随膜系变化 | 小–中 |
| 8.4 | **发腮补偿选项（Auto Panatar 式）+ C 风格说明更正** | 调研发现：ARRI Master Anamorphic 最近对焦时挤压比仍为 2.00 ± 0.03（厂方数据表 H/V 放大率），Panavision C 系列本身也是发腮已校正的。我们的 C 风格 2.01 → 1.69 是 **1950 年代未校正前置变形器**的行为。做法：加 `mumps_correction`（0 = 未校正，1 = 完全校正），用对焦联动的柱面组旋转（Wallin US 2,890,622 原理）或辅助柱面变焦实现；需要先让追迹器支持**任意角度旋转的柱面**（同时是 Caldwell 预设的前提） | C 风格在 1.0 时 MFD 挤压比 ≥ 1.95；UI / README 写清楚 0 = 「1950s CinemaScope」，1 = 「现代校正」；保持 0.7 的默认观感 | 中 |
| 8.5 | **杂光的 ISO 9358 标定** | 杂光核改为「核心 + 幂律尾 + 常数」，参数随视场与波长变化；加一个 VGI 回归场景（白场中的黑点） | VGI 测得值等于预设设定值 ±10%；各预设的取值标明是估计（公开实测不存在） | 小 |
| 8.6 | **Geometry 模式亚像素平移**（旧问题 §7.2） | 单片透镜复现 → 查像素中心约定 | 偏移 < 0.05 px | 小 |
| 8.7 | **外部数据回归** | 新测试 `test_reference.py`：前置预设的散景高宽比随离焦趋向挤压比；后置 PV 1.34× 散景接近圆（ASC / FDTimes 的定性结论）；呼吸方向以垂直为主（E 系列、Hawk 的描述）；最近对焦距离与 Panavision 公布值比对 | 全部通过或在文档里解释差异 | 小 |

## 平台风险（持续）

- Blender 5.x 手册：自定义相机只在 OptiX 上支持 GPU，Metal / HIP / CUDA 都不支持，也没看到计划。**GPU 内核补丁是长期维护成本**：每个 Blender 版本跑 `bl_gpu.py` / `bl_gpu_ghosts.py`，补丁锚点失配时自动退回 CPU（已有）。
- 自定义相机没有 Vector pass，运动矢量合成不可用——文档里写明。
- 竞品：Lens Sim（Blender 4.5+ OSL 相机）。我们的差异：真实变形专利、GPU on Metal、物理鬼影。

### B. 公开实测 / 厂方数据（可做回归的）

- **ARRI/ZEISS Master Anamorphic 数据表（2016-04）**：各焦距最近对焦时 H / V 放大率 → 挤压比 1.97–2.01；还有最近对焦距离、入瞳位置、15 片光圈。是最好的「发腮已校正」参照。
- Laowa 的示意：未校正 1.8× 在 0.7 m 降到 1.62×（厂商示例，非实测）。
- FDTimes 2015 变形专刊：传统变形畸变「通常 6–12%」；Hawk 长焦变焦呼吸从 20% 优化到 4%；Neil：前置柱面的散景高度变大、宽度与同焦距球面镜相近，2× 镜头景深比约 4:1；后置变形变焦没有椭圆散景。
- Panavision C / E / G / T / Ultra Panatar II、Hawk V-Lite、Cooke Anamorphic/i、Atlas Orion、LOMO、Sirui 的 T 值、最近对焦、前径（RESEARCH.md §3.5 已有 C/E/G）。
- 炫光颜色只有定性描述：C 蓝紫（Sasaki 说改镀膜厚度变成红蓝）、E 干净的蓝、Ultra Panatar II 暖色。
- **没有公开数据**：任何电影变形镜头的实测挤压比–对焦距离曲线、散景高宽比、暗角档数、ISO 9358 杂光、畸变网格、T/f 透过率。所以 8.5 的杂光值和 8.4 之外的发腮量级只能标为估计。

### C. 渲染技术

- 物理炫光：Hullin 2011（我们已覆盖大部分，缺鬼影光圈的衍射振铃）、Lee & Eisemann 2013（傍轴矩阵，可做预剔除）、Joo 2016（瑕疵散景）、多项式鬼影（2024）。
- 相机模型：Hanika 2014（光圈瞄准）、Schrade 2016（稀疏多项式，不假设旋转对称）、神经网络方法都只做旋转对称镜头，不适合。
- **没有找到物理渲染变形镜头的论文**——现有工作都假设旋转对称或在后期伪造；这正是本项目的位置。
- Hero wavelength（Wilkie 2014）**不适用**：色散让每个波长在场景里走不同光线，相机着色器只能返回一条。
- 镀膜：单层 MgF₂ @550 nm 约 1.3%、两端 2–3%（残余反射偏品红）；三层 QHQ 宽带膜 < 0.5%。蓝色拉丝来自经过柱面组的鬼影路径（沿光焦度方向展开），颜色来自镀膜设计波长——8.3 应能不加特殊处理地复现。
